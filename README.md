# Laravel Web App - Women Techpower
## Overview
This project is a Laravel-based web application designed to manage events, job postings, mentorship programs, and user accounts. It features CRUD operations, authentication and a responsive frontend to ensure a seamless user experience.

## Features
### User Authentication & Access Control
- User registration & login system
- Role-based access control (Admin, User, Guest)
- Secure password hashing and session management
### Event & Job Management
- Create, update, delete, and view events and job postings
- Detailed event and job descriptions
### Mentorship Program
- Add and manage mentorship opportunities
- Interactive user engagement with mentorship details
### API & Database Integration
- RESTful API endpoints for external integrations
- Eloquent ORM for database interactions
- Secure data validation and form handling
## Project Structure
- app/ → Controllers, Models, Middleware for business logic
- database/ → Migrations and seeders for structured data
- routes/ → Web and API route definitions
- resources/views/ → Blade templates for frontend UI
- public/ → Static assets (CSS, JavaScript, Images)
## Technologies Used
- Laravel (Backend Framework)
- MySQL (Database)
- Blade Templates & TailwindCSS (Frontend)
- RESTful API & Middleware
- Composer & NPM (Dependency Management)
